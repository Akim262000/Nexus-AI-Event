# Nexus-AI-Event
Nexus: AI Event Landing Page

Это лендинг страница для саммитов, конференций и технологических мероприятий, посвященных искусственному интеллекту.

Проект не предназначен для коммерческого использования или промышленного развёртывания.

Он демонстрирует базовые концепции веб‑разработки и может служить шаблоном для начинающих.

* [Ссылка на готовый проект](https://akim262000.github.io/Nexus-AI-Event/ "Демо-версия приложения Habitus")
* [Я использовал макет от Olga](https://www.figma.com/design/Hit8Db0N7cW7VzmlwsmNAU/Nexus--AI-Event-Landing-Page--Community-?node-id=27-135&t=L6T7Q1DkTel9YQr6-0 "Исходный дизайн-макет в Figma")


## Этот проект был создан в учебных целях для:
* закрепления навыков работы с **HTML5**, **CSS3**, **Bootstrap 5** и **JavaScript (ES6+)**;
* освоения принципов построения интерактивных пользовательских интерфейсов;
* отработки структуры статического веб‑приложения.

## Применяются различные технология:  

Проект построен на классическом стеке веб‑разработки:
* **HTML5** — структура страницы;
* **CSS3** — стилизация и **адаптивный дизайн** (в т. ч. ручная адаптация под мобильные устройства — исходный макет был только для ПК);
* **Bootstrap 5** — готовые компоненты (карточки, кнопки, сетка), адаптивность и JavaScript‑плагины;
* **JavaScript (ES6+)** — интерактивность, логика приложения.
